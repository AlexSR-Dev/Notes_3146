03 - The CIA Triad:

A Foundation of Information Security:
- A foundational concept in info security and CS. A framework that security professionals use to categorize,
evaluate security threats, attacks, and protections.

- CIA triad is necessary prior to protecting an organization's information assets and infrastructure to run safetly.


What is the CIA Triad?
- A security model made up of three core principles that any secure system should uphold:
• C - Confidentiality
• I - Integrity
• A - Availability

- They all work together, allowing threats to be identified under which part/s of the CIA triad they threaten.

Visualized as three interlocking cirlces:
• Confidentiality, represented by a KEYHOLE ICON, symbolizes something private only select individuals can unlock or access.
• Integrity, represented by a CHECKMARK ICON, symbolizes that the data has been verified as correct and unaltered.
• Availability, represented by a POWER BUTTON ICON, symbolizes that a system is 'on' ready to be used.

- All three parts must work.




Confidentiality:
- Information is kept private and secure, accessible to authorized individuals/systems.

Thought as a LOCKED SAFE / SAFETY DEPOSIT BOX. Keeps sensitive information protected from being viewed or accessed
by unauthorized people.
- Only manner for controlled access is correct password, encryption key, or authorization.
- A magnifying glass represent the risk of someone with unauthorized access.

Real-World Threats to Confidentiality:
• Spyware (software that secretlyu monitors and collects you information).
• Phushing (tricked into providing private information, logins).
• Unauthorized access or "snooping" on data by people without permission.




Integrity:
- Data that should not be modified, deleted, or added to by unauthorized persons/systems.

Is about TRUSTWORTHINESS and ACCURACY of data. In that files, records, and messages you can trust is exactly
how it was created and is not changed, corrupted, or tampered with.
- Violations to integrity can be: unauthorized ADDING, CHANGING, or DELETING of data.

Real-World Threats to Integrity:
• A hacker altering financial records or grades in a database.
• Malware that corrupts files.
• Viruses that insert unauthorized code into programs.

NOTE:
If you can't trust the data that may have been tampered with, you wouldn't be able to make good decision from it.




Availablity:
- Systems and data are available to whomever and whenever they require/needs them.

Even if the information is kept with Confidentiality and integrity, its useless to people with authorization can
access it when needed. Thus, it about KEEPING SYSTEMS UP, RUNNING, and REACHABLE.
- Information must stay operational at all times for authorized users.

Real-World Threats to Availability:
• Denial-of-Service Attacks, in which an attack floods a system with traffic so legitimate users cannot get through.
• Bombs, sabotage, or physical destruction of equipment, physical security can also take a system offine just like digital attacks.
• Power outages, hardware failures, or overloaded system.





Putting the Triad Together:
C       Confidentiality         Keeps info private to select users/systems              Keyhole
I       Integrity               Keeps info accurate and unaltered from                  Checkmark
                                unauthorized parties/systems.
A       Availablity             Allows authorized users to access                       Power Button
                                systems/data when needed.

- Thought as a connected set of requirements. A weakness in any one of these undermine the overall security of a system.
• A system thats perfectly available and has accurate data, but unauthorized people can read it, confidentiality has failed.
• Data kept completely private and readily available, but an attacker can secretly alter it, integrity has failed.
• Data is private and untampered, but the system crashes and legitimate users can't reach it, availability has failed.

- Overall requires balancing and protecting of these three simultaneously.





Why This Matters Going Forward:
CIA Triad is a tool for analysis. Which you will ask:
• Which part of the triad does this threat target and is it more than one?
• What would the real-world consequence be if that principle were violated?
• What protections/controls would help defend against this specific risk?
